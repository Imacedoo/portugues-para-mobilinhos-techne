# 🏆 Português para Mobilinhos - Projeto Vencedor Téchne Escola Móbile 2025 

## 🎓 Sobre o Projeto

Este projeto foi desenvolvido para o **Téchne** (Concurso de Tecnologia e Criatividade da Escola Móbile) por **2 alunas da Escola Móbile**, com minha tutoria em parceria com uma coordenadora da Escola.

### 🌟 Conquistas

O projeto foi **vencedor de 2 prêmios na edição de 2025**, alcançando a **maior premiação**:

- 🥇 **Melhor Projeto de 6º Ano**
- 🥇 **Melhor Projeto do Fundamental 2**

### 👩‍💻 Desenvolvimento

- **Desenvolvido 100% pelas alunas**
- **Plataforma:** Google AI Studio
- **Tema:** Jogo educativo de português onde as crianças ajudam um sapo a identificar substantivos, adjetivos e verbos em frases, navegando por níveis com desafios de tempo

---

## 🛠️ Informações Técnicas

### Tecnologias Utilizadas

- **React 19.1.1** - Framework front-end
- **TypeScript** - Linguagem de programação
- **Vite** - Build tool e dev server
- **Google AI Studio** - Plataforma de desenvolvimento

### Como Funciona

O aplicativo é um jogo educativo interativo que ensina gramática portuguesa de forma divertida. As crianças identificam classes gramaticais (substantivos, adjetivos e verbos) em frases apresentadas, com desafios cronometrados em diferentes níveis.

### 💻 Rodar Localmente

**Pré-requisitos:** Node.js

1. **Instale as dependências:**
   ```bash
   npm install
   ```

2. **Configure a chave da API Gemini:**
   
   Defina o `GEMINI_API_KEY` no arquivo [.env.local](.env.local) com sua chave de API do Gemini

3. **Inicie o servidor de desenvolvimento:**
   ```bash
   npm run dev
   ```

4. **Acesse o aplicativo:**
   
   Abra seu navegador em `http://localhost:5173`

### 📦 Scripts Disponíveis

- `npm run dev` - Inicia o servidor de desenvolvimento
- `npm run build` - Cria a build de produção
- `npm run preview` - Visualiza a build de produção localmente
